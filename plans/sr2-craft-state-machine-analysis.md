# 飞船状态机——用最简单的话说明白

## 先说一个生活中的例子

想象你站在操场上，操场上有很多人：

1. **离你太远的人**——你只能看到一个小黑点，看不清是谁，也不知道他在干嘛
2. **离你不远不近的人**——你能认出来那是张三，也能看到他穿什么颜色的衣服，但他具体在做什么动作你看不太清楚
3. **离你很近的人**——你能看清他的一举一动，他在跑步还是在跳，你全知道

游戏里的飞船也是这样的。

## 飞船的 5 种状态

### 状态 1：远到看不见（远程未加载）

**什么意思：** 你的飞船在太空的另一边，离你有几十万公里远。

**游戏知道它吗？** 知道。游戏还记得"哦，那个地方有一艘飞船"，但只知道它在什么轨道上转，其他的一概不知。

**这艘船上的小蓝人还活着吗？** 没人知道。游戏不管他了。如果我们在游戏里不加处理，等你跑过去看的时候，小蓝人可能已经饿死了。

### 状态 2：能看见但摸不着（视觉加载——这就是你说的"中间状态"）

**什么意思：** 这艘飞船已经飞到了你能看到的范围内。比如你在月球轨道上，另一艘飞船在离你几十公里的地方飘着。你能用眼睛看到它，也能用雷达锁定它。

**游戏知道它吗？** 知道得很详细。游戏已经把它的"档案"从硬盘里读出来了——这艘船上有什么零件、装了多少氧气、每个小蓝人是谁，全知道。

**但这艘船能动吗？** 不能。游戏不计算它的物理——它不会掉下来、不会撞到东西、引擎不会点火。它就像一个贴在背景上的贴纸，只是看起来在那儿。

**这艘船上的小蓝人在呼吸吗？** 不呼吸了！出大事了——游戏不计算这艘船上的任何东西，所以小蓝人的氧气不会减少，水不会变少，饭不会变少。时间像是停住了。

### 状态 3：能看见也能摸到（物理加载）

**什么意思：** 这就是你当前正在驾驶的飞船，或者就在你旁边几米远的飞船。

**游戏怎么做？** 游戏全力计算这艘船上的一切——引擎、重力、碰撞、还有小蓝人喝水吃饭呼吸。

**小蓝人在呼吸吗？** 在呼吸。每秒钟都在消耗氧气。

### 状态 4：刚才还摸得到，现在摸不到了（物理卸载）

**什么意思：** 你旁边的那艘飞船慢慢飘远了，飘到了几百米外。你还能看到它，但已经没办法碰它了。

**游戏知道它吗？** 知道，档案还在内存里（状态 2 那样）。但物理已经关了。

**小蓝人还呼吸吗？** 又停了。这就是另一个"中间状态"。

### 状态 5：按了时间加速（Warp）

**什么意思：** 你按了"时间加速"按钮，想快进到几天后。

**发生什么：** 游戏先把所有飞船的"物理"关掉（不管是你开的还是别人的），然后快速计算轨道——就像按了快进键一样。

**小蓝人还呼吸吗？** 如果没人管，还是不呼吸。但我们的系统就在这时候干活！

## 什么距离决定什么状态

游戏用**三个圈**来判断飞船在哪个状态（以你的飞船为中心）：

```
    最外圈（视觉圈）：看到飞船 → 加载档案
    中间圈（物理圈）：开始计算物理
    内圈（卸载圈）：停止计算物理
```

```
←←←←←←←←←←←←← 视觉圈（加载档案）→→→→→→→→→→→→→→→→
          ←←←←←← 物理圈（开始计算）→→→→→→→→→→
          ←← 卸载圈（停止计算）→→

状态1          状态2         状态3      状态4         状态1
───┬────────────┬────────────┬──────────┬────────────┬───
   │            │            │  玩家     │            │
   │  视觉圈     │  物理圈     │  飞船     │  卸载圈    │  视觉圈
   │  最外面     │  中间       │          │  内圈      │  最外面
```

## 我们的系统在做什么？

发现没有？状态 2、4、5 中有一个**大问题**：

> **小蓝人不呼吸了！**

这就是 Kerbalism 的后台系统要解决的问题——也正好是我们的系统要干的活。

游戏原本的处理是：
- 你看着那艘船 → 不管它 → 小蓝人假装不需要呼吸
- 等你想起来，切过去一看 → 小蓝人早就憋死了

我们的系统做的事很简单：

> **我们当"保姆"——定期检查每艘船上的小蓝人，帮他们把该吃的吃该喝的喝算清楚。**

不管飞船在哪个状态（只要游戏还知道这艘船的档案），我们的系统就偷偷跑过去，算算这段时间过去了多久，然后：
- 氧气少了多少 → 扣掉
- 水少了多少 → 扣掉
- 饭少了多少 → 扣掉
- CO₂ 多了多少 → 加上
- 辐射累计了多少 → 加上

## 总结成一句话

**飞船有 5 种状态，但只有 1 种（你正在开的那艘）有人在管。其他 4 种状态下，小蓝人的生命维持是停摆的。我们的系统就是负责在所有状态下都帮小蓝人算账，让他们不管在哪里都不会饿死。**
