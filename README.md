# Droodism Mod (v0.797) - Life Support for SimpleRockets2(Or J:NO)

**Latest Update: June 20 , 2026**

> **Warning**: Hundreds of Droods were killed the making of this mod. Start a new game save when using this mod!

---

## Overview

Droodism is a SimpleRockets mod that adds a **Life Support** system for Droods and Tourists. Your crew now requires **oxygen**, **food**, and **water** to survive, bringing realism and challenge to your missions. Running depletes resources faster, so plan carefully!

---

## Key Features

- **Life Support Mechanics**: Droods and Tourists consume oxygen, food, and water. Depleting these resources causes gradual damage and eventual death.
- **Resource Monitoring**: A new **Inspect Panel** displays all resource amount on your craft. Monitor them before time-warping or leaving your crew unattended!
- **Habitable Planets**: Droods do not consume oxygen in the atmospheres of habitable planets (**Droo**, **Earth**, **Kerbin**, **Nebra**, **Laythe**).
- **Radiation Belt**: Planets now have procedural radiation belt which could cause life long radiation to your crew
  ***For more detailed info please read [User Manual](https://drive.google.com/file/d/1zPcpjuDYL9fbhsv2g1zWnhUoeLa70Arx/view?usp=drive_link)***
